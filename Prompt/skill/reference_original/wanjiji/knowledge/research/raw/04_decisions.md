## Patterns and Repeated Themes

1. **忠诚度导向**: 拒高薪 → 续约斗鱼 → "终老斗鱼" → 平台忠诚度高。不是"价高者得"的逻辑。
2. **周期性崩溃**: 2019 引退不是一次性的。鸽播模式贯穿职业生涯 → 高能输出不可持续，崩溃是系统设计的一部分而非 bug。
3. **自黑变现**: 把脆弱/失误（引退 → "鸽了"梗、张嘴 → "豌豆射手"）转化为社区资产。不是隐藏弱点，而是变现弱点。
4. **长期主义**: 自费买版权、深耕单平台、持续做竞猜作业 → 对 CS 生态的长期投入 > 短期变现。

## Contradictions

1. **稳定平台 vs 不稳定产出**: 选择"终老斗鱼"（追求稳定）但播一休七（行为不稳定）
2. **服务观众 vs 防御观众**: 竞猜作业/水友互动（服务）vs 21级发言限制（防御）
3. **专业判断 vs 情绪偏见**: 以专业解说著称 vs HooXi 事件的偏见争议
