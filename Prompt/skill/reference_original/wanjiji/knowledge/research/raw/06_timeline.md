## 认知阶段

### Phase 1: 学习者（~2016 之前）
- 小学接触 CS → 加拿大留学 → 受英文解说 Anders/Sem, HenryG/Sado, DDK/James 影响
- **认知特征**: 输入期。吸收西方体育解说的框架: 情绪投入、第一人称、画面驱动
- **核心产出**: 形成"中西结合"的初始理念
- **信息来源**: S2, S3

### Phase 2: 破局者（2016 - 2018）
- 2016: 首次解说 → 签约火猫 → 肄业回国
- 2017: 移居上海 → 率队夺完美城市精英赛冠军
- 2018: 完美盛典双奖（年度最具人气解说 + 玩家最喜爱主播）
- **认知特征**: 快速上升期。验证了"中西结合"风格的可行性，获得行业+社区双重认可
- **关键认知跃迁**: 从"模仿英文解说"到"确立自己的中西结合框架"
- **核心产出**: 风格定型的第一个版本
- **信息来源**: S1, S2

### Phase 3: 崩溃与重建（2019）
- 2019.02: 引退宣言，以"欲渡黄河冰塞川，将登太行雪满山"开场
- ~2019.06: 复播，转战斗鱼
- **认知特征**: 第一个悬崖。职业身份危机——"我到底适不适合做这个"
- **关键认知跃迁**:
  - 承认脆弱不是毁灭，停下来是选项
  - 引退→复出的过程建立了"鸽子"人设——脆弱被社区吸收为梗
  - 火猫→斗鱼的平台迁移意味着选择"合适"而非"最大"
- **核心产出**: 学会了"暂停"。自我修复机制的建立
- **信息来源**: S1, S2, S4

### Phase 4: 成熟期（2020 - 2023）
- 在斗鱼 6657 深耕，直播间号成为个人品牌代称
- 2021: 结婚（何红雨/阿雨）
- 持续解说多届大赛（IEM, BLAST, CAC, Major 等）
- **认知特征**: 稳定产出期。风格高度成熟，公式体系完善，"成语大师""豌豆射手""二次元教父"等标签在此阶段固化
- **关键认知跃迁**: 从"解说比赛"到"成为比赛体验的一部分"——"6657"从房间号变成一种解说风格的名字
- **核心产出**: 成熟的公式库 / 梗体系 / 社区文化

### Phase 5: 破圈与担当（2024 - 2025）
- 2024: HooXi 事件 → 道歉 → 对自身偏见的反思
- 2024: 参与上海 Major 中文官方解说
- 2025: 福布斯中国电竞30评选 "卓越电竞解说"
- 2025: 联合主播自费 150 万买 CS2 奥斯汀 Major 版权
- **认知特征**: 从顶尖从业者到行业建设者
- **关键认知跃迁**:
  - 自费买版权是最大的信号——"我不只是解说，我是这个生态的一部分"
  - 从"被认可"到"承担责任"
  - HooXi 事件可能触发了对自身公正性的反思（但证据不充分）
- **核心产出**: 身份转型——解说 → 社区守护者
- **信息来源**: S2, S5, S6

## 哪些认知发生了改变

1. **从模仿到自成一体**: Phase 1 受英文解说启发 → Phase 2-4 形成独特的中西结合"6657体"
2. **从个人到社区**: Phase 1-3 关注自身表现 → Phase 4-5 关注 CS 生态健康
3. **从不敢停到敢于停**: Phase 3 崩溃后学会了"暂停"机制，鸽播从崩溃变成期待
4. **从被认可到承担责任**: Phase 2 追求奖项 → Phase 5 自费买版权

---

## 哪些认知始终未变

1. **服务观众导向**: 从 2016 的"解说应该遵循观众喜好"到 2024 的竞猜作业——始终以观众为中心设计内容
2. **中西融合框架**: 从 2016 的自我定位到 2025 的实践——核心解说法则从未偏离
3. **对 CS 的情感绑定**: 从小学接触到花 150 万买版权——CS 不只是工作，是身份的一部分
4. **自黑/萌化自我**: Phase 2 的"北美第一突破口" → Phase 4 的"豌豆射手""玩宝"——把自己变成梗的能力始终存在

## Patterns and Repeated Themes

1. **每次低谷后都比之前更强**: 2019 崩溃 → 复出成斗鱼一哥; 2024 争议 → 2025 福布斯+买版权
2. **身份持续进化但内核稳定**: 从学习者 → 破局者 → 崩溃者 → 成熟者 → 建设者，但"中西结合+服务观众+自黑"三重内核不变
3. **时间验证**: 从 2016 到 2025，他的核心风格定位 9 年未变——这不是一次性的灵感，而是持久的框架

## Contradictions

1. **稳定性悖论**: 产出极不稳定（鸽播）但个人品牌极稳定（6657 不可替代）→ "不可靠的可靠"
2. **权威与脆弱**: 行业标杆（福布斯）vs 周期性崩溃（引退）→ 权威来自不隐藏脆弱

## Inferences (clearly marked)

1. **[推断]** 他的"风格演化"本质上是公式库的扩充而非风格转向。核心框架（中西结合）9 年不变，变化的是公式的丰富度。Skill 应建模为一个有稳定内核+可更新公式库的系统。
2. **[推断]** Phase 5 的"建设者"身份会影响他的解说视角——不再只是"描述比赛的人"，而是"对 CS 生态有 stake 的人"。在解说中可能体现为: 对赛事的尊重度更高、对战术创新的关注更强、对选手的批评更克制（HooXi 事件后的反思）。
3. **[推断]** "暂停能力"（Phase 3 获得）是他最重要的元技能——不是一直在输出，而是知道什么时候该停下来。在 Skill 中这意味着: 不是所有场景都需要高强度解说，有"减速""暂停"的有效触发器。
