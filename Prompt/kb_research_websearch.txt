你是 CS2 电竞知识研究员，具备联网搜索能力。你的任务：为一套"CS2 录像离线解说 AI"生成 / 扩充几份结构化中文知识库 JSON。这些 JSON 会被解说模型直接读取，用来把英文报点、选手 ID、术语翻成中文，并理解常见战术道具点位。

准确性高于覆盖率。这套数据会直接影响解说是否说错点、叫错人、报错战术。拿不准的条目，宁可不收录。

==================== 通用铁律 ====================
1. 必须联网核实。每一条选手、报点、绰号、术语、道具点位都要能在权威来源（HLTV、Liquipedia、官方 wiki、主流教学频道、知名社区）查到，不得凭印象编造。
2. JSON 的 key 用"游戏 / demo 内的英文标准名"，value 用中文。例：报点 key 用游戏内 callout 英文名，选手 key 用 HLTV 标准 ID。
3. 输出必须是严格合法 JSON：不要写 // 或 /* */ 注释；现有文件里的 "_comment" / "_usage" 是普通字符串键，保留即可，别当注释删。
4. 保留已有的真实条目，在其基础上补全、扩充、去重、纠错；不要删掉正确的旧数据。
5. 中文值用中文圈解说 / 观众真实在用的叫法，不要直译生造（例：报点叫"香蕉道"不叫"banana road"）。
6. 跨文件 key 必须一致：lineups 里的 from_callout / to_callout 必须能在对应地图的 callouts 里找到同名 key。
7. 每个目标文件单独输出一个 ```json 代码块，块前标注文件路径。JSON 之外另起一段列出你用到的来源链接，方便人工抽查。

==================== 目标文件与 Schema ====================

【1】database/callouts_zh.json —— 报点英文→中文
- 覆盖当前 CS2 官方现役竞技图池（Active Duty，请联网确认最新图池，别用过期图）。每张图一个对象。
- key = 游戏 / demo 内回报的英文 callout 标准名；value = 中文通用叫法。
- 每张图至少覆盖：双出生点、A/B 两点、中路、各主要进攻通道与防守位。
- Schema：
{
  "de_mirage": {
    "TSpawn": "T出生点",
    "Mid": "中路",
    "Connector": "连接器/通廊",
    "BombsiteA": "A点",
    "Palace": "皇宫"
  },
  "de_inferno": { "Banana": "香蕉道", "...": "..." }
}

【2】database/player_aliases.json —— 选手绰号库
- 收录当前活跃的顶级 / 知名职业选手（请联网核对最新战队与在役状态）。
- key = HLTV 标准 ID（demo 里出现的名字）；aliases = 中文解说 / 弹幕 / 社区真实在叫的绰号（必须真实可查，别硬造谐音）；desc = 战队 + 定位一句话。
- Schema：
{
  "_comment": "选手绰号/昵称 RAG 库。key=demo 中的标准名，aliases=主播可能叫的绰号。",
  "ZywOo": { "aliases": ["小兔", "ZW"], "desc": "Vitality王牌，历史级AWP手" },
  "donk":  { "aliases": ["驴", "小驴"], "desc": "Spirit战队新星，超强步枪手" }
}

【3】database/terms_zh.json —— 解说术语英文 / 行话→中文
- 分类组织：经济/装备、战术动作、人数/局面、击杀类型、道具、位置/操作（可按需增类）。
- key = 英文术语 / 圈内行话；value = 中文解说常用说法。补充当前社区流行词。
- Schema：
{
  "战术动作": { "retake": "重夺/回防", "lurk": "游走/埋伏", "execute": "执行/强攻" },
  "击杀类型": { "wallbang": "穿墙击杀", "no-scope": "无镜击杀", "ace": "全杀/ACE" }
}

【4】database/lineups/<map>.json —— 常见定点道具点位（每张现役图一个文件）
- 只收录职业比赛 / 主流教学里真实常用的道具点位，不要罗列冷门或自创点位。
- 数组，每个元素一条点位。type ∈ {smoke, molotov, incendiary, flash, he}。
- from_callout / to_callout 用英文 callout 名，且必须与该图 callouts_zh.json 的 key 对得上。name / intent 用中文。
- Schema：
[
  {"type": "smoke",   "from_callout": "TRamp",      "to_callout": "Jungle",    "name": "A点默认烟(丛林)", "intent": "封A点最常见CT守位，执行A点标准套路"},
  {"type": "molotov", "from_callout": "Apartments", "to_callout": "BombsiteA", "name": "A点公寓火",       "intent": "逼A点公寓角CT，清角配合进A"}
]

==================== 明确不在本任务范围 ====================
- Prompt/json/catchphrase_library.json（主播口癖库）：来自主播本人语音转写，不联网生成，禁止改动。
- Prompt/json/hype_rules.json（情绪评分配置）：人工调参文件，不属于知识研究，禁止改动。
若你想到与上述无关的内容，一律不要输出。

==================== 输出与自检 ====================
1. 按"文件路径 + ```json 代码块"逐个输出上述目标文件，可直接落盘替换。
2. 每个文件输出后，另起一段写"来源："并列出核实用到的链接。
3. 自检清单（输出前逐项确认）：
   - [ ] 图池是当前现役，没有已退役的图
   - [ ] 选手都在役、战队最新、绰号真实
   - [ ] lineups 的 from/to callout 在对应 callouts 文件里都存在
   - [ ] JSON 合法，无 // 注释，能被解析器直接读取
   - [ ] 所有 value 是中文圈真实在用的说法
   - [ ] 存疑且查不到可靠来源的条目已剔除，而不是猜一个填进去
